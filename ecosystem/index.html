RUNNABLE CONTRACT PROOFS

Verify the difficult parts.

These focused repositories exercise real Daptin surfaces end to end. They are implementation evidence, not invented customer stories.

LLM API CONTRACT

Official OpenAI SDK compatibility

Exercises model listing, chat, streaming, completions, embeddings, usage, and structured errors through Daptin’s /v1 routes.

Open demo ↗ IDENTITY PROVIDER

OAuth 2.0 and OpenID Connect

Runs authorization code with PKCE, confidential token exchange, client registration, userinfo, and Daptin consuming its own provider.

Open demo ↗ PRODUCT CONTROLS

Metering, quotas, and credits

Demonstrates metered CRUD and model usage, hard quota denial, usage audit records, credit wallets, and post-metering debits.

Open demo ↗ CREDENTIAL BOUNDARIES

Per-user integration authentication

Tests OAuth tokens and encrypted custom credentials, including ownership checks and wrong-user denial paths.

Open demo ↗ COMPOSITION

Provider and consumer instances

Runs two Daptin instances through the standard OAuth authorization-code flow without a helper application server.

APPLICATION STARTING POINTS

Move from capability
to product shape.

The application repositories range from reusable schemas to complete interfaces. Older examples are labeled honestly: useful for understanding the model, not promises of a current design system.

SCHEMASSchema samples

Blog, FAQ, store, construction, payment, style, transaction, and todo resource models.

 COMPLETE APPDadadash

An office-style application with workspaces, tables, files, documents, spreadsheets, and calendars.

 HISTORICAL EXAMPLEImage gallery

A compact example of asset columns, a cloud store, a schema, and a hosted frontend.

A frontend starter showing the JavaScript client, Docker Compose, and imported schemas.
