# Post-review copy report

This report lists the current copy produced by the product-positioning review. Every line presents Daptin as stable product infrastructure: it states the capability Daptin provides, the predictable contract applications use, and the standards or protocols that connect each feature to the wider system.

Review rules used:

- Name the concrete capability already supplied by Daptin.
- Describe the contract that remains consistent across clients, data growth, or deployment changes.
- Prefer a specific operation or engineering consequence over abstract phrases such as “shared context,” “product surface,” or “operating controls.”
- Give every feature page a unique claim tied to its capability and operating benefit.
- Present AI routing and usage accounting as current capabilities with concrete backend contracts.
