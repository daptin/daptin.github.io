OAuth 2.0 + OpenID Connect

Run Daptin as an OAuth 2.0 and OIDC provider.

Register a client, complete authorization code with PKCE, obtain tokens, and read the signed-in user. The server's provider tests additionally reject invalid redirects and authorization-code replay.

Per-user credentials

Keep each user's provider credential isolated.

Store OAuth or API credentials for each user and execute an installed operation with the matching secret. The demo verifies that one signed-in user cannot use another user's credential.

Run the integration-auth demo ↗

Usage, quotas, and credits

Apply quotas and record credit hooks.

Record API calls and model tokens, set a plan quota that rejects excess requests, and write usage and debit records. The included credit hook runs after metering, so align a prepaid balance with the plan quota instead of treating the wallet alone as a limit.

Older schema examples

Older schemas, useful as syntax references.

The schema-samples repository contains YAML and JSON definitions for blogs, FAQs, stores, payments, transactions, and todos. Its latest published changes are from 2020, so treat it as a syntax reference and compare each model with the current schema documentation before starting a new application.
